## 🚀 Work Process Summary

In this assignment, I built a structured webpage from scratch to understand the core principles of front-end development.

* I started by creating the HTML skeleton, adding semantic tags, lists, tables, and a functional form.
* Then, I transitioned from inline and internal styles to an external CSS stylesheet to cleanly separate content from design.
* Finally, I applied intermediate CSS concepts, including the Box Model (margins, padding, borders), various positioning methods (static, relative, absolute), sizing units (px, %, rem), and legacy float-based layouts. The project was successfully deployed using GitHub Pages.
