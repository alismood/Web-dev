## 🚀 Work Process Summary

First, I used Flexbox to create a navigation bar with a logo and links, and a row of three equal-height cards with a hover effect. Next, I used CSS Grid to set up a page layout with a header, sidebar, main content, and footer, along with a nine-image gallery that shows a caption when hovered. Then, I combined both tools to build a portfolio page by using Grid for the main page sections and Flexbox for the header and project card items. Through this work, I learned that Flexbox is great for lining up items in one direction, while CSS Grid is better for organizing rows and columns at the same time. Using both together makes it easy to build the main page structure with Grid and align the smaller content inside it with Flexbox
