Responsive Layout with CSS Media Queries

Desktop: 3 boxes side by side | Tablet: 2 boxes on row 1, 1 on row 2 | Mobile: Stacked vertically.

Mobile

Takes 100% width on mobile, 48% on tablet, and 32% on desktop using Flexbox and Media Queries.

Tablet

Pairs up with Box 1 on tablet viewports (768px to 991px) and sits in the center on desktop screens.

Desktop row

Drops to the second row on tablet viewports, and aligns as the third column on desktop screens.

Bootstrap 12-Column Responsive Grid

Using col-12 (Mobile: stacked), col-md-6 (Tablet: 2 on first row, 1 on second), and col-lg-4 (Desktop: 4 columns each / 3 equal parts).

Bootstrap Column 1

Classes: col-12 col-md-6 col-lg-4. Automatically adapts using Bootstrap's 12-column flexbox grid.

Bootstrap Column 2

Classes: col-12 col-md-6 col-lg-4. Sits next to Column 1 on tablet and desktop screens.

Bootstrap Column 3

Classes: col-12 col-md-6 col-lg-4. Moves to the second row on tablets and joins row 1 on desktop.
